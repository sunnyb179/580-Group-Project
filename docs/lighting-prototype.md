# Lighting prototype

Open Assets/Scenes/light.unity for the daytime cloud-particle prototype.
Open Assets/Scenes/light_night_test.unity for the nighttime lighting and distance-fog prototype.

These are separate test scenes; a runtime day/night switch is not implemented yet.
Clouds use alpha-blended billboard particles, not volumetric clouds.
Night fog uses scene distance fog, not volumetric fog.

Light_CloudTexture.png was generated with OpenAI image generation for this prototype.
Tree assets are from mozankatip/StylizedTrees; see Assets/ThirdParty/StylizedTrees/LICENSE.txt.

The empty Assets/Scripts/light directory is reserved for future lighting scripts.
